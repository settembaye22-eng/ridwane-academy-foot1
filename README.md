# Ridwane Academy Foot — RAF — Version 1

Première version statique de la homepage officielle.

## Technologies
- HTML5
- CSS3
- JavaScript vanilla
- Logo officiel fourni par le projet

## Structure

raf_v1/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── assets/
    └── logo-raf.jpg

## Lancer le projet

Ouvrir `index.html` dans VS Code avec Live Server, ou utiliser :

```bash
python -m http.server 5500
```

Puis ouvrir http://localhost:5500
